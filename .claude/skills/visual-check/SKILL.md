# Visual Check スキル（ビジュアル検証）

Figmaのデザインと実ページのスクリーンショットを比較し、差異を検出・修正します。

**引数:** `$ARGUMENTS` — `[Figma URL] [ページURL]`

- 第1引数（必須）: FigmaのURL
- 第2引数（必須）: 対象ページのURL（例: `http://localhost:3000/service/`）

---

## Step 1: 前提条件の確認

**`dist/` フォルダの存在を確認する。**

`dist/` フォルダが存在しない場合:
→「`dist/` が未生成のためビジュアルチェックをスキップしました。`cd gulp && npx gulp` を実行後に再度お試しください。」と報告して終了する。

---

## Step 2: Figmaスクリーンショットの取得

FigmaのURLからパラメータを抽出する:
- `fileKey`: `/design/` 直後の文字列
- `nodeId`: `node-id=` の値（`-` を `:` に変換）

Figma MCP の `get_screenshot` ツールでデザインのスクリーンショットを取得する。

---

## Step 3: 実ページのスクリーンショット撮影

Playwrightで引数のページURLに接続する。

接続に失敗した場合:
→「開発サーバーが起動していないためビジュアルチェックをスキップしました。`cd gulp && npx gulp` を実行後に再度お試しください。」と報告して終了する。

接続成功後:
1. PC幅（1440px）でスクリーンショットを撮影する
2. SP幅（375px）でも撮影する
3. 撮影した画像を `.claude/tmp/` に保存する

---

## Step 4: 比較チェック

Figmaのスクリーンショットと撮影画像を以下の観点で比較する:

| 観点 | チェック内容 |
|------|-------------|
| レイアウト・形状 | 全体構成・サイズ・余白が一致しているか |
| タイポグラフィ | フォントサイズ・行高・文字色が近似しているか |
| カラー | 背景色・要素色がデザインと一致しているか |
| 余白・間隔 | 内部のpadding・要素間のmarginが適切か |
| レスポンシブ | SP（375px）での表示が適切か |

---

## Step 5: 問題の対応

差異を発見した場合:
1. 差異の内容を具体的に記述する
2. 原因となるSCSSプロパティを特定して修正する
3. **修正後、再度スクリーンショットを撮影して改善を確認する**
4. 改善されない場合や、デザイン判断が必要な場合は報告にとどめる

---

## Step 6: 完了報告

以下の形式で報告する:

**撮影ファイル:** [スクリーンショットのパス]

**比較結果:**
| 観点 | 結果 | 詳細 |
|------|------|------|
| レイアウト・形状 | OK / 差異あり | [差異の説明と対応] |
| タイポグラフィ | OK / 差異あり | |
| カラー | OK / 差異あり | |
| 余白・間隔 | OK / 差異あり | |
| レスポンシブ | OK / 差異あり | |
